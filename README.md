# 塞孚思充電管理中控台 V8.6.9

本版為 V8.6.8 專案封裝結構修正版，保留右上角帳號資訊、閒置倒數與自動登出功能。

## 專案結構
- `index.html`：Vite 專案入口
- `src/`：Vue 應用程式（App.vue、views、components、style.css）
- `public/`：靜態資源與 Excel 範本
- `package.json`：專案依賴與指令

## 執行
```bash
npm install
npm run dev
```

## 本版確認項目
- 員工端右上角顯示姓名、員工編號、閒置倒數及登出。
- 管理者端右上角顯示管理者名稱、閒置倒數及登出。
- 系統設定頁包含閒置自動登出設定。
- 閒置提醒視窗及「繼續使用」功能保留。

注意：本專案目前為前端展示原型，尚未串接正式本機資料庫或實體 RFID 控制器。
