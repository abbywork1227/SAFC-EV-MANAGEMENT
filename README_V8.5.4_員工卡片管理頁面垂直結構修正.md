# V8.5.4 員工／卡片管理頁面版面修正

本版依使用者確認的版面重新整理 EmployeesView.vue 的 template 結構。

## 修正內容
1. 查詢條件區獨立於列表外框上方，不再與「授權卡片清單」標題並排。
2. 授權卡片清單標題、資料表格及其 10 筆分頁位於同一個垂直區塊。
3. 卡片綁定異動紀錄標題、資料表格及其 10 筆分頁位於同一個垂直區塊。
4. 上下兩組列表仍位於同一個白底圓角大框內，且上下排列。
5. 兩組分頁維持獨立，不互相影響。
6. 保留原有匯出、查詢、綁定、解除綁定、掛失、標記損壞、停用、恢復授權、管理者權限與員工帳號啟用操作。
7. 保留原有統計卡片、提示文字及各操作對話框。
