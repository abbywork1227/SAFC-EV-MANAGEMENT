# V8.4.2 畫面調整說明

## 設備狀態
- 將「充電完成（暫定功能）」及「逾時占用（暫定功能）」兩張狀態卡移到設備狀態標題下方、設備清單上方。
- 移除原本額外的暫定功能說明橫幅。
- 充電完成的說明改為：可依電流停止達設定時間判斷充電停止；不代表車輛已離開。
- 故障中仍由管理者手動設定。

## 統計報表
- 設備使用次數長條圖改採固定且可延伸的數值刻度（至少 0–5 次），長條依實際次數占刻度比例顯示。
- 加上橫軸數字，避免只有視覺長度卻沒有尺度。

## 員工／授權卡片
- 解除綁定改為先選擇原因：離職繳回、人員異動、更換卡片、卡片收回、其他；選其他需輸入原因。
- 卡片停用新增停用原因、起始日及停用期間設定；預設示意規則為扣點達 3 點停用 3 個月。
- 停用及解除綁定異動寫入卡片異動紀錄示意。

## 員工積點
- 改為「違規扣點」概念，不提供加點。
- 累計扣點達 3 點，暫定停用 RFID 卡片 3 個月。
- 所有扣點及停用規則仍標示暫定，待客戶確認。

注意：本版仍為前端互動原型；資料目前存於 Vue 元件狀態，重新整理後不保留，尚未連接本機資料庫或讀卡控制器。正式版需實作停用起訖日、期滿自動恢復授權及稽核紀錄。
