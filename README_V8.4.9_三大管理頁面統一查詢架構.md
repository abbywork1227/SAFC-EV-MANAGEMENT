# V8.4.9 三大管理頁面統一查詢架構

本版將「設備總覽／狀態管理」、「員工／卡片管理」與「員工積點（暫定功能）」統一為相同頁面結構：

1. 頁面上方先放匯出／管理操作按鈕。
2. 統計卡片（各頁面原有者保留）。
3. 單一共用查詢列，位於主要資料列表之前。
4. 主要資料列表。
5. 下方歷史／異動紀錄列表。
6. 查詢條件只設定一次，套用到同頁的主要資料與歷史紀錄。
7. 匯出按鈕位於頁面上方；歷史紀錄匯出只匯出紀錄資料，不匯出主要資料清單（卡片清單另保留既有獨立匯出）。

## 設備總覽／狀態管理
- 上方匯出設備狀態異動紀錄。
- 共用搜尋：設備編號、名稱、狀態、原因、操作人員。
- 共用日期：異動開始／結束日期。
- 查詢同步套用設備卡片清單及下方設備狀態異動紀錄。
- 匯出只輸出符合條件的設備狀態異動紀錄。

## 員工／卡片管理
- 上方保留匯出卡片清單、匯出綁定異動紀錄及新增員工。
- 共用搜尋：卡片 UID、員工姓名／編號、異動原因、操作人員。
- 共用日期：綁定異動開始／結束日期。
- 查詢同步套用授權卡片清單及下方卡片綁定異動紀錄。
- 匯出綁定異動紀錄只輸出符合條件的紀錄；卡片清單仍可獨立匯出。

## 員工積點（暫定功能）
- 延續 V8.4.8：上方匯出扣點紀錄。
- 單一共用查詢列套用員工累計扣點及下方違規扣點紀錄。
- 匯出只輸出符合條件的違規扣點紀錄。
