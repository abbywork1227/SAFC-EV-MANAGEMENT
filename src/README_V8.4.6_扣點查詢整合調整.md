# V8.4.6 扣點查詢整合調整

1. 員工違規扣點頁移除「暫定功能｜扣點及停用規則待客戶確認」整段說明文字。
2. 「員工違規扣點（暫定功能）」與「違規扣點紀錄（暫定功能）」合併為同一個頁面區塊：上方呈現員工目前累計扣點與管理操作，下方呈現每筆扣點歷史。
3. 查詢條件集中於區塊上方，提供員工編號／姓名搜尋、扣點開始日期、扣點結束日期、查詢及清除條件。
4. 日期區間套用於扣點歷史紀錄；員工累計扣點仍顯示目前累計值，不會因選擇歷史日期而改變。員工關鍵字可同步篩選上方員工清單及下方扣點紀錄。
5. 匯出扣點紀錄按鈕維持左上方，匯出目前已套用日期與員工搜尋條件的紀錄。

注意：此版仍為前端互動原型，資料需於正式版串接本機資料庫。
