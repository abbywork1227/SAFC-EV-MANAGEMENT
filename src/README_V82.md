# V8.2 畫面調整說明

- 設備狀態管理頁新增「設備狀態異動紀錄」匯出 CSV。
- 統計報表日期條件改為可套用，使用次數、24 小時時段統計、設備統計及尖離峰推估依篩選結果更新；目前仍為專案內的示意資料。
- 員工／卡片管理整併為單一「授權卡片清單」頁面，以卡片 UID 為主，直接綁定員工、查看卡片狀態及管理者／員工帳號狀態。
- 移除員工 CSV 匯入及匯入範本下載，避免批次匯入造成卡片授權資料混亂；保留清單匯出與新增員工。
- 移除「中控台系統時間」設定卡片，時間直接採用電腦作業系統時間。
- QR Code 管理及公告管理細項頁面頂端均新增「返回系統設定」。

注意：仍為前端展示原型，卡片控制器同步、正式資料庫及 USB 實際檔案作業尚未串接。
