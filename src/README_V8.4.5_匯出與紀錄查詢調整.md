# V8.4.5 匯出按鈕與紀錄查詢調整

1. 各主要頁面的匯出操作統一集中在內容區左上方工具列：統計報表、使用紀錄、設備狀態異動、員工／授權卡片管理、卡片綁定異動紀錄、員工違規扣點紀錄。
2. 員工／卡片管理頁：卡片清單匯出、卡片綁定異動紀錄匯出與新增員工操作集中在左上方；綁定異動紀錄新增起訖日期查詢，匯出依目前已套用的日期條件輸出。
3. 員工違規扣點頁：新增扣點紀錄 Excel 匯出；新增扣點時間起訖日期查詢，匯出依目前已套用的日期條件輸出。
4. 移除員工人數、本月扣點次數、管理者登記扣點三張統計卡。
5. 設備異動紀錄匯出改為 Excel 相容 .xls 格式，並移至左上工具列。
6. 使用紀錄匯出按鈕移至左上工具列。

注意：本版仍為前端互動原型，異動與扣點資料目前存在元件狀態；正式版需串接本機資料庫。報表 Excel（USB）按鈕仍為示意提示，正式版需實作實際檔案輸出。
