# V8.4.4 修正內容

1. 設備總覽的「故障中」及「維修中」統計合併為「故障／維修中」，數量為兩種狀態的加總；設備個別狀態仍保留故障中、維修中供管理者設定。
2. 設備卡片桌面版調整為每列 5 台；使用者姓名移到管理者狀態下拉選單下方。
3. 移除使用紀錄頁不需要的說明句。
4. 移除員工／授權卡片管理頁不需要的說明句。
5. 修正扣點跳轉的停用視窗狀態：跳轉開啟一次後，立即清除父層暫存員工 ID，避免日後直接進入卡片管理頁又自動開啟前次員工的停用視窗。
6. 卡片綁定異動紀錄新增「匯出 Excel」按鈕，匯出 .xls 檔，欄位包含異動時間、卡片 UID、原綁定員工、新綁定員工、異動原因及操作人員。

注意：目前仍為前端展示原型，異動紀錄與操作資料尚未連接正式本機資料庫／控制器。
