# V8.4.7 管理列表與異動紀錄統一版型

本版依照確認後的頁面結構調整：每個管理頁面保留主要資料列表，並在下方獨立呈現異動／歷史紀錄。

## 1. 設備狀態管理
- 上半部保留設備狀態統計卡與設備卡片列表。
- 設備清單新增設備編號／名稱搜尋。
- 下半部為設備狀態異動紀錄。
- 異動紀錄區塊左上方提供 Excel 匯出。
- 異動紀錄提供起訖日期及關鍵字查詢（設備、狀態、原因、操作人員）。
- 匯出依目前套用的異動紀錄篩選條件輸出。

## 2. 員工／卡片管理
- 保留上方授權卡片清單、卡片搜尋及卡片管理操作。
- 卡片清單匯出及新增員工仍在主要列表上方。
- 下方卡片綁定異動紀錄獨立呈現。
- 綁定異動紀錄區塊左上方提供 Excel 匯出。
- 綁定異動紀錄提供起訖日期及關鍵字查詢（UID、原／新綁定員工、原因、操作人員）。
- 匯出依目前套用的異動紀錄篩選條件輸出。

## 3. 員工違規扣點
- 上方保留員工累計扣點列表及手動扣點操作，提供獨立員工搜尋。
- 下方保留違規扣點紀錄。
- 扣點紀錄區塊左上方提供 Excel 匯出。
- 扣點紀錄提供起訖日期及關鍵字查詢（員工編號、姓名、扣點原因）。
- 匯出依目前套用的扣點紀錄篩選條件輸出。

## 注意
本版仍為前端互動原型，紀錄資料尚未串接正式本機資料庫。Excel 匯出為瀏覽器產生的 Excel 相容 .xls 檔案；正式 USB 儲存流程仍需整合。
