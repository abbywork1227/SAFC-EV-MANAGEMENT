# V8.4.1 修正說明

1. 修正 ExtrasView.vue 的 Vue template 分支順序：設備狀態頁明確使用 page==='equipment'，積點頁成為獨立的 v-else-if 分支，避免 Vite 編譯錯誤。
2. 設備狀態說明調整：電流感測可推估充電開始／停止；停止不等於車輛已離開。
3. 故障中及維修中均由管理者手動設定，儲存時填寫原因並留下設備狀態異動紀錄。
4. 員工／授權卡片管理新增「卡片綁定異動紀錄」，展示綁定、解除綁定、掛失／損壞等異動的時間、UID、原／新綁定員工、原因及操作人員。

注意：本版仍為前端示意，綁定異動紀錄目前存在 Vue 元件狀態中，正式版需寫入本機資料庫。尚未接讀卡控制器或正式資料庫。
