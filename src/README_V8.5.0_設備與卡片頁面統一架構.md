# V8.5.0 設備與卡片頁面統一架構

依確認，設備總覽／狀態管理、員工／卡片管理改採員工積點頁面的上下式 UI 架構。

## 設備總覽／狀態管理
- 匯出設備異動紀錄按鈕置於頁面最上方。
- 保留原有設備狀態統計卡。
- 共用查詢列位於主要設備清單之前。
- 關鍵字搜尋同時篩選設備清單及下方設備狀態異動紀錄。
- 起訖日期只篩選下方設備狀態異動紀錄，不影響目前設備清單。
- 原有設備卡片樣式、欄位、狀態下拉選單及卡片排列均保留，不重新設計。
- 「儲存設備狀態」按鈕維持在設備卡片列表下方。
- 下方接續設備狀態異動紀錄。

## 員工／卡片管理
- 匯出卡片清單、匯出綁定異動紀錄及新增員工操作集中在頁面上方。
- 保留原有卡片統計及授權卡片資料列表。
- 共用查詢列位於主要卡片清單之前。
- 關鍵字搜尋同時篩選授權卡片清單及下方卡片綁定異動紀錄。
- 起訖日期只篩選下方卡片綁定異動紀錄，不影響目前授權卡片清單。
- 下方接續卡片綁定異動紀錄。

## 共通查詢原則
- 關鍵字：同時篩選上方主要資料及下方紀錄。
- 日期：只篩選下方歷史紀錄。
- 查詢：套用目前條件。
- 清除條件：恢復完整資料。

本版以現有前端互動原型為基礎，未變更正式資料庫或硬體介接。
