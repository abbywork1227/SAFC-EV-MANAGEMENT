# V8.4.3 畫面與操作調整

1. 設備頁移除重複的「設備狀態」大標及小標；六種狀態卡（可使用、使用中、故障中、維修中、充電完成〔暫定功能〕、逾時占用〔暫定功能〕）整合為同一列，窄螢幕自動換行。
2. 設備卡片在使用中時顯示目前使用者姓名（示意資料）。
3. 設備統計圖改為單欄排列，所有設備共用同一條完整橫軸刻度。
4. 員工卡片管理補齊解除綁定原因視窗、停用原因說明、停用起始日及結束日；停用保留員工與卡片綁定關係，停用期滿可由管理者恢復授權。
5. 員工積點頁新增「手動扣點」按鈕及扣點原因欄位，扣點後更新累計點數與異動紀錄；達 3 點時可選擇跳轉至卡片管理並開啟停用設定視窗。
6. 移除設備、報表、員工卡片、使用紀錄及系統設定頁面與全域頁首重複的主標題。

注意：
- 本版仍為前端互動原型，資料未持久化至本機資料庫。
- 使用中員工姓名為展示用對應資料，正式版應由充電事件／讀卡紀錄關聯取得。
- 停用日期目前可設定並記錄，但期滿自動恢復控制器授權尚未實作；正式版需依停用結束日排程恢復授權。
- 扣點門檻、逾時占用判斷及停用規則仍屬暫定，需客戶確認。
- 本環境未安裝 node_modules，無法執行 Vite build。
